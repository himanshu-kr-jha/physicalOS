Leave empty to detect defects from the video. Attach one to use its rows as the findings instead — they already carry a position, so nothing is detected or projected and the run finishes in seconds. Columns: object_id, frame, time, defect_name, lat, lon, chainage_km, frame_url. time is video time (M:SS), lat/lon decimal degrees — blank borrows the nearest keyframe's position. Produce one from an existing run with pos export-csv --run runs/<name>.
